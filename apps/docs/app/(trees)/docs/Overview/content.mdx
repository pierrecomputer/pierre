## Overview

<Notice variant="warning" icon={<IconFlagFill />}>
  **Trees is in beta.** Start from the public React, vanilla, and SSR entry
  points on this page. Expect refinements and small API changes between beta
  releases.
</Notice>

**Trees** uses one path-first model. The model works the same across React,
vanilla, and SSR hydration. Selection, focus, search, rename, drag and drop, Git
status, and row annotations all use canonical paths.

These docs are guide-first. First, select your runtime. Next, shape the tree
data before it reaches the UI. Then add search, item actions, styling, icons,
row signals, or SSR when you need them.
