### Package Exports [toc-ignore]

The package provides several entry points for different use cases:

| Package                       | Description                                                                                                                 |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `@pierre/diffs`               | [Vanilla JS components](#vanilla-js-api), plus [utility functions](#utilities)                                              |
| `@pierre/diffs/react`         | [React components](#react-api) for rendering diffs and files                                                                |
| `@pierre/diffs/edit`          | Low-level [edit mode](#edit-mode) `Editor` for attaching editing to rendered file and diff components                       |
| `@pierre/diffs/ssr`           | [Server-side rendering utilities](#ssr) for pre-rendering diffs with syntax highlighting                                    |
| `@pierre/diffs/worker`        | [Worker pool utilities](#worker-pool) for offloading syntax highlighting to background threads                              |
| `@pierre/diffs/highlighter/*` | Highlighter backends (`shiki-wasm`, `shiki-js`, `highlights`) that load on demand when selected with `preferredHighlighter` |

Shiki with WebAssembly (`'shiki-wasm'`) is the default highlighter. Set
`preferredHighlighter` to `'shiki-js'` or `'highlights'` in file, diff, or
worker pool options to switch backends; `@pierre/highlights` is installed as a
dependency of `@pierre/diffs`, so no extra install is needed.
