## Core Types

Before diving into the options and components, it's helpful to understand the
core data structures used throughout the library.

### FileTreeOptions

`FileTreeOptions` is the main options object for `FileTree`. Use it when
creating a vanilla `FileTree` instance or when rendering the React
`<FileTree options={...} />` component. It defines the file list, instance id,
flattening behavior, selection callback, and optional headless tree config.

**Tip:** To pre-render the tree on the server, use
[`preloadFileTree`](#utilities-preloadfiletree) from `@pierre/file-tree/ssr` and
pass the returned HTML as the `prerenderedHTML` prop (React) or to `hydrate()`
(vanilla). See [SSR](#ssr) for usage.

### FileTreeSelectionItem

`FileTreeSelectionItem` describes one item in the tree selection. Your
`onSelection` callback receives an array of these. Each item has a `path` (the
file or folder path) and `isFolder` (whether it's a folder or file).

### FileTreeSearchMode

`FileTreeSearchMode` controls how search affects the tree. Pass it via
`config.fileTreeSearchMode` in `FileTreeOptions`. Use `'expand-matches'`
(default) to expand nodes that match the search, or `'collapse-non-matches'` to
hide non-matching branches so only matching paths and their parents stay
visible.

### HeadlessTreeConfig

`HeadlessTreeConfig` is the optional `config` object inside `FileTreeOptions`.
It is a subset of the headless tree's config: FileTree wires up the data loader,
root, item names, and features for you. You can pass `initialState` (expanded
items, selected items, focused item), `fileTreeSearchMode`, and optionally
`setState` for controlled state updates.
