## FileTree options

All options you can pass to FileTree (or to TreeApp via `fileTreeOptions`).

### The `initialFiles` option

The tree is built from an array of file paths (strings). Folders are inferred
from path segments; use forward slashes. Top-level paths (e.g. `README.md`) and
nested paths (e.g. `src/components/Button.tsx`) are both valid.

`Button.tsx`.

### Options reference

`initialFiles` is the only required option, all others are optional.

| Option                    | Description                                                                                                                                                                                         |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `initialFiles`            | **Required.** Array of file paths (strings). Defines the list and hierarchy.                                                                                                                        |
| `id`                      | Unique identifier for this instance (DOM ids, SSR). Default: e.g. `ft_brw_1`.                                                                                                                       |
| `flattenEmptyDirectories` | When `true`, single-child folder chains become one row (e.g. `build / assets / images` → `build · assets · images`). Default: `false`. [Live demo](/trees#flattening).                              |
| `useLazyDataLoader`       | When `true`, children load when a folder is expanded. Default: `false`.                                                                                                                             |
| `gitStatus`               | Optional `GitStatusEntry[]` used to show Git-style file status (`added`, `modified`, `deleted`). Folders with changed descendants also receive a change indicator. [Live demo](/trees#path-colors). |
| `onSelection`             | Callback when selection changes. Receives `FileTreeSelectionItem[]` (`path`, `isFolder`). See example below.                                                                                        |
| `config`                  | Extra headless-tree options: `initialState`, `fileTreeSearchMode`, `setState`. See table below.                                                                                                     |

### config sub-options

| Sub-option                  | Description                                                                                                                                                                                          |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config.initialState`       | Initial state: `expandedItems` (path or flattened ids; use `f::` prefix for flattened, e.g. `f::build/assets/images`), `selectedItems` (e.g. `['package.json']`), `focusedItem` (item id or `null`). |
| `config.fileTreeSearchMode` | `'expand-matches'` (default) — expand matching nodes; `'collapse-non-matches'` — hide non-matching branches.                                                                                         |
| `config.setState`           | Optional callback for controlled state updates (advanced).                                                                                                                                           |
