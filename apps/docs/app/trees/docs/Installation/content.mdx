## Installation

[published as an npm package](https://www.npmjs.com/package/@pierre/file-tree).

### Package Exports [toc-ignore]

The package provides several entry points for different use cases:

| Package                   | Description                                                                                   |
| ------------------------- | --------------------------------------------------------------------------------------------- |
| `@pierre/file-tree`       | [Vanilla JS API](#vanilla-js-api) and [utility functions](#utilities) for building file trees |
| `@pierre/file-tree/react` | [React component](#react-api) for rendering file trees with full interactivity                |
| `@pierre/file-tree/ssr`   | [Server-side rendering utilities](#ssr) for pre-rendering the tree with fast first paint      |
